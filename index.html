Personal Cybersecurity Project

Cybersecurity Monitoring & Attack Detection Lab

A hands-on beginner lab that demonstrates how repeated failed login attempts can be identified from log data using PowerShell.

Project overview

This project demonstrates a basic security-monitoring workflow: read login-event records, count failed attempts, and raise an alert when a threshold is reached within a short time window.

FocusFailed-login monitoring and basic attack detection
ToolsWindows 11, PowerShell, CSV log data
Detection rule5 or more failed logins within 5 minutes

How it works

  1. Login-event records are stored in a CSV file with timestamp, username, source IP, and result fields.
  2. A PowerShell script reads the records and groups failed attempts by username and source IP.
  3. The script checks whether the number of failures reaches the configured threshold within five minutes.
  4. If the threshold is reached, the script displays an alert for investigation.

What I learned

  • How login-event logs can support security monitoring.
  • How to process CSV data with PowerShell.
  • How to apply a simple threshold-based detection rule.
  • Why repeated authentication failures may need investigation.

Scope and next steps

This is a small learning lab, not a production SIEM or a validated intrusion-detection system. A useful next improvement would be to export real Windows failed-logon events, parse them, and compare the results with the sample-data test.
